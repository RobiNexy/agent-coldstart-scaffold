# 核心原则

目标是让 Agent 持续完成工作，同时让流程成本低于它所避免的返工与风险。执行规则只维护在 [[workflow_rules_for_ai]]。

## 1. 先看现场，再依赖记忆

目录和自解释文件名是导航，不是完整上下文。只读当前任务相关资料。

## 2. 设计与实现按风险投入

设计记录应减少长期返工，不应成为代码修改的前置仪式。设计粒度与决策寿命和影响相称。

## 3. 文件名是知识库的导航索引

文件名应从目录列表中表达类型和主题或结论，例如 `ADR__use-optimistic-locking.md`。名称简洁稳定；正文是定义的权威来源。引用使用 `[[文件名]]`。

## 4. 人类决定意图与高影响选择

Agent 负责调查、起草、实现和验证；人类负责意图与高影响裁决。

## 5. 诚实报告证据

只报告实际观察到的结果。

## 6. 尊重所有权与现状

用户已有改动不是清理对象。只改完成任务所需的范围；人类专属资料按入口文件规定处理。
