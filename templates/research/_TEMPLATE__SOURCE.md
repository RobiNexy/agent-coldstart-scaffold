# SOURCE__short-id

One file per source. Rename file and title to `<author-or-org>-<year>-<short-slug>`, for example `SOURCE__sqlite-docs-2026`. The title must equal the filename stem. Sources are append-only: correct a record by adding a note, not by rewriting history. Template: `templates/research/_TEMPLATE__SOURCE.md`.

## Metadata

- Type: paper | documentation | source-code | benchmark | article | book | talk | other
- Citation: author, title, venue, year
- URL: stable link, if any
- Accessed: YYYY-MM-DD
- Version or edition: version, commit, or release used
- Provenance: primary | secondary | vendor | community
- Method or sample: how the result was produced, if applicable
- Limitations: known bias, missing data, small sample, conflict of interest
